Privacy Policy

Last updated: August 2026

Trove is a portfolio project that helps users understand their Gmail inbox by generating AI-powered summaries. This Privacy Policy explains how Trove handles information when you use the application.

1. Information We Access

When you connect your Google account, Trove requests read-only access to Gmail through the Gmail API.

This access allows Trove to retrieve email information required to generate summaries and organize email information within the application.

2. Gmail Permissions

Trove requests Gmail read-only access. Trove does not use this permission to send, modify, or delete emails.

3. AI Processing

Retrieved email content may be processed using the Google Gemini API to generate summaries and extract useful information such as actions, deadlines, and categories.

4. Stored Information

Trove stores summarized email information in a PostgreSQL database so that previously generated summaries can be retrieved across sessions.

The application does not intentionally store your Google account password.

5. Authentication

Google OAuth 2.0 is used to authenticate users and obtain the permissions required for Gmail integration.

6. Data Security

Application credentials, API keys, OAuth secrets, and database credentials are handled through environment variables and should not be exposed in the application's source code.

7. Data Sharing

Trove does not intentionally sell personal information. Information required for the application's functionality may be processed by the external services used by Trove, including Google services such as the Gmail API and Gemini API.

8. Data Removal

Saved summaries can be removed through the application's available removal functionality.

9. Changes to This Policy

This Privacy Policy may be updated as the Trove project evolves. Changes will be reflected on this page.
